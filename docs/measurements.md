# Замеры Claude desktop

Снято 2026-11-02 с Claude desktop на этом ПК (Linux, Hyprland, масштаб 1, окно 1908×1023, тёмная тема).
Сам снимок в репозиторий не кладём: в нём личные чаты. Числа ниже в пикселях при масштабе 1, это и есть dp
в Compose Desktop. Константы лежат в `ui/Metrics.kt`, цвета вида Graphite в `ui/theme/Theme.kt`.

## Окна оболочки (из app.asar)

Главное окно: заголовок свой, остальное грузится с claude.ai. Отдельные окна оболочки: Quick Entry
(маленькое поле поверх всего), About, Find in page, просмотр файлов, окно согласия на локальный запуск.
Минимальная ширина окна 720 (в коде есть minWidth 720, 600 и minHeight 560).

## Что сделано так же в cl0udly

Рамка, сайдбар, колонка, поле ввода, Chat/Code, поиск по Ctrl+K, настройки страницей со списком разделов
слева (как в Claude), Quick Entry (Ctrl+Shift+Space внутри окна → маленькое поле), About.
Цвета и шрифты меняет вид; размеры рамки у всех видов одни.
