Первая версия cl0udly для компьютера: тот же клиент OpenCode, что на телефоне ([cl0udly-mobile](https://github.com/mistqkw/cl0udly-mobile)), в рамке Claude desktop.

**Установить** (Linux x64):

```bash
curl -fsSL https://raw.githubusercontent.com/mistqkw/cl0udly-desktop/main/get.sh | bash
```

Или скачай `cl0udly-desktop-v0.0.1-beta-1-linux-x64.tar.gz` ниже, распакуй и запусти `cl0udly/bin/cl0udly`.

**Что умеет**
- Чаты и Code с проектами, терминал, браузер, изменения и файлы в боковых панелях
- Чаты и память сами переезжают между телефоном и компьютером, когда они в одной сети. Включи Настройки → Code → Remote Control и отсканируй QR телефоном
- «Запомнить это?»: агент предлагает услышанное о тебе карточкой, решаешь ты
- Саб-агенты командой: добавляй их в выборе модели, они знают весь разговор
- Память в виде графа в боковой панели, импорт и экспорт (подходит и архив памяти из Claude)
- OpenCode ставится и обновляется сам: новая версия сначала проходит проверку, в Настройки → Server можно вернуть прошлую
- Русский и английский, облачко-маскот с играми, голосовой разговор, таймлайн задачи, предупреждения о лимитах
- Фото, видео и аудио от агента плитками, ответы оформлены как в Claude

Это бета, баги будут. Неофициальный клиент, не связан с разработчиками OpenCode.
